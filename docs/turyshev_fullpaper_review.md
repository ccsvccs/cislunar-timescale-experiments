# Turyshev 全文复核：TT–TDB 的剩余候选与 TCL/TL 扩展边界

审阅日期：2026-11-10。主依据为固定的
[arXiv:2507.22145v2 PDF](sources/turyshev_2507.22145v2.pdf)（47页），
不以日期与附录编号有差异的在线 HTML 替代原 PDF。
全文阅读覆盖 Sec. I–VI、Appendices A/B；关键公式由独立审阅及 PDF 视觉核查确认。
本轮只做文献、代数与代码审查，没有更改物理实现或重新运行数值实验。
下列量级估算均不是新的 DE440 残差实测或误差验收。

## 1. 决策结论

- 严格复现式(21)时，应继续保留现有 Phase 1，不向其中无说明地加入完整理论项。
- 若目标是1977锚点以来的亚皮秒完整物理模型，不能宣称再无值得核查的项：
  太阳自旋直接势是明确候选，月球非球形外势是接近当前目标的边缘候选。
- 两者是否属于 DE440 原时间模型均未确认；不能通过加入它们追逐 JPL 残差。
- 可以把月心 TCL↔TDB 作为后续主线；TT支线保留未达到1ps的状态与来源限制。
  TL应作为明确约定的线性缩放层，具体月面钟固有时另立阶段。

## 2. TT–TDB 尚值得核查的项

### 2.1 太阳直接自旋势

v2 p35式(A5)、(A8)、(A9)，p40式(A33)、(A34)、(A39)给出相关原式。
令 r_B=x_E−x_B，S_B为外体角动量，在原始一致的BCRS尺度下：

\[
\delta\boldsymbol w_B=-\frac{G(\boldsymbol r_B\times\boldsymbol S_B)}{2r_B^3},
\qquad
\delta D_B=\frac{2G\boldsymbol v_B\cdot(\boldsymbol r_B\times\boldsymbol S_B)}{r_B^3}.
\]

将标量和向量自旋贡献一起代入正向时间integrand，得到

\[
\delta F_{\rm spin}
=\sum_{B\ne E}\frac{2G(\boldsymbol v_E-\boldsymbol v_B)\cdot
(\boldsymbol r_B\times\boldsymbol S_B)}{c^4r_B^3}.
\]

对应本项目输出的速率再乘 A=(1−L_G)/(1−L_B)。转写到TDB-compatible输入时，
自旋参数也应声明一致尺度。不能仅添加向量自旋、漏掉标量自旋。
当前 [jpl_model.py](../src/tt_tdb/jpl_model.py) 的向量势仅含平动项，标量PN四项也没有自旋。

式(A39)给出太阳自旋向量势约 c⁻³|δw|∼1.04×10⁻¹⁷，叙述再乘v_E/c得到
约1.03×10⁻²¹；式(A34)的实际向量势系数为4。完整向量项的特征尺度约
4×10⁻²¹，须以上述组合计算最终贡献，不能把原文叙述当作完整自旋项的严格上界。
作为纯量级检查，10⁻²¹的非零平均速率经过约49年对应1.55ps；4.12×10⁻²¹
的恒定累计尺度约6.37ps。这不是实际轨道积分结果，不证明有同样大小的DE440误差。

Park公开式(3)–(7)未列直接自旋项。轨道中已有Lense–Thirring动力学摄动，
并不等于直接自旋时间势已进入integrand；是否加入必须区分“完整物理诊断”与
“复现JPL公开时间模型”。目前不能声称该项会改善约2ps残差。

### 2.2 月球非球形外部势

式(A5)及p35的w_L说明原则上涵盖所有外体多极势，p42式(B4)给出月球球谐结构。
以原文月球参数估算，地心处月球J2项的特征速率尺度为

\[
\frac{\mu_M}{c^2r_{EM}}J_{2M}\left(\frac{R_M}{r_{EM}}\right)^2
\sim6\times10^{-22}.
\]

其49年恒定累计尺度接近0.9ps；实际角度、平均、C22等项和姿态会改变结果。
该数字既非严格界，也不是已测累计贡献。长至1100年时更不能直接忽略。
本文J2/C20记号和符号存在需要回原始重力模型核对的问题，不应凭表格猜实现。
目前无证据证明DE440时间函数包含这些直接项。

### 2.3 已包含与不应误加的项

- Phase 2已实现太阳J2、外体平动向量势和主要天体的四个PN标量分项。
- 小体、环的输入身份和高阶项仍按现有映射报告列为限制；本文未提供新的真实状态或GMSDOT规则。
- GCRS自身潮汐/惯性势式(A16)/(A17)在X=0为零，式(A31)位置项在地心为零。
  这不意味着外体月球自身的多极势在地心也为零。
- Sec. V的月面钟自身势、站点/航天器运动、潮汐响应，以及光传播的Shapiro/Sagnac项，
  属于具体钟或信号映射，不能直接加入地心TT–TDB。
- 外部弱场c⁻⁶项的朴素尺度约10⁻²⁴，49年约0.0015ps，仅支持暂缓；这不是全项严格误差界。

论文的5×10⁻¹⁸速率阈值和0.1ps周期振幅阈值，不保证1977以来累计误差小于1ps。
式(21)本身就保留了随历时增长的余项。已有式(22)比例与平均常数问题继续以
[model_audit.md](model_audit.md)为准。

## 3. TCL/TL 的自然扩展与代数核查

### 3.1 先TCL，再约定TL

月心积分需要排除月球自势、加入地球外势，并使用真实月球重心状态。
现有DE440 reader已有所需中心状态，数值框架可复用；外部Earth J2等贡献须单列审计。
[LTE440](https://github.com/xlucn/LTE440)的BSP/TPC可作为TCL−TDB独立对照，
不能成为核心integrand输入。

v2 p10式(39)定义

\[
TL=(1-L_L)TCL+L_LTL_0.
\]

作者建议L_L=3.13905×10⁻¹¹，TL_0未选定；L_H是模型长期平均，
L_M应从(1−L_M)=(1−L_L)(1−L_H)推导，不能把三者都当独立精确定义常数。
[CGPM Resolution 6 (2026)](https://www.bipm.org/en/cgpm-2026/resolution-6)
讨论TCL及其约定缩放，并未固定该TL或此L_L数值；若选择缩放，建议原点与TCL一致。
本文TL数值应标为实验约定，不能冒称国际标准。

### 3.2 式(43)→(44)的比例

PDF p11视觉核查：式(43)的A_M=(1−L_L)/(1−L_B)覆盖整个积分与位置括号，
式(44)的周期项和位置项未显写该因子。
若明确按TDB定义ΔP_H^s=∫(F_M−L_H)ds，则其贡献为A_MΔP_H^s；
不能无说明地删掉该因子。若沿用TCB定义的P_H，必须写明变量与函数重定义。
式(44)常数从L_L变L_M本身是正确恢复平均项的代数结果。
对1.651ms年项，省略A_M的特征差约25.55ps，不能作为亚皮秒精确恒等式使用。
因此实现应从式(39)及完整TCL原始积分出发。

### 3.3 比较事件与积分下端点

现有地心TT_E(TDB)和月心TCL_M(TDB)在共同TDB标签下的差，是两个中心事件的时间值差。
式(45)使用r_E=r_EM+r_M，描述同一空间事件的坐标变换。
这两种比较的几何项不同，不能混用其周期振幅作为验收标准。

PDF p14式(56)→(57)涉及总导数d(v_E·r_EM)/dt。通常定积分保留上下两端；
与显式几何项抵消上端后，仍有(v_E·r_EM)(t_0)/c²下端常数。
原文未显写该常数。可重新声明原点吸收它，但不能保持原同一TL_0又无说明删除。
两个中心的共同TDB比较还会保留约126µs月周期；同一月心事件的TT坐标映射会抵消
这部分当前时刻几何项，因此不能直接用式(58)/(62)约0.47µs周期验收前者。

式(58)按式(59)严格积分时，线性系数是(L_G−L_L)/(1−L_B)−L_EM；
式(62)写成(L_G−L_L−L_EM)/(1−L_B)，两者差约2.65×10⁻¹⁹。
这落在作者截断尺度内，但对长期ps目标不能视作精确相等。

## 4. 后续建议

1. 将完整直接自旋势和月球非球形外势保留为TT的独立候选诊断，不改变Phase 1或既有验收结果。
2. 月球主线先建立月心TCL↔TDB，对照LTE440的完整周期项与线性项，并复用独立求积检查。
3. 再明确实验L_L、原点、比较事件，构建TL线性层与TL↔TT组合。
4. 具体月面站或航天器钟的固有时、姿态和高阶重力场另立阶段。

这是一份科学审阅与扩展边界记录，不代表本轮已经实现或验证TCL/TL。
