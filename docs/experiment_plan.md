# 冻结的实验设计（运行前制定）

核心定义保持不变：Δ=TDB−TT，anchor=T0+TDB0，不以任何reference输出校准anchor。F2−C_exact与F4独立通道累计，便于开启/关闭c⁻⁴。

1. 先运行无需星历的时间表示、解析椭圆轨道与积分器测试。
2. 官方完整DE440、同套GM：构造地球质心=EMB+地球相对EMB；外部天体为Sun、Moon及其他行星系统，排除Earth/EMB。
3. J2000起连续32day短段，1/0.5/0.25day和Romberg阶数6/8/10，独立GaussLegendre阶数16；记录max/RMS/95%差值与调用数，不设置预先的10fs结论。
4. 从1977 anchor积分至2026-01-01，输出2024-01-01至2026-01-01的每日时间差。保存全部累计缓存，年度图至少两年。
5. 完整Romberg10与独立GaussLegendre16都从同一真实anchor累计，核查长期数值误差。对同区间短时积分用mpmath高精度权重/公式验证，明确星历输入仍为double。
6. 诊断ERFA差异、JPL真实时间星历（若取得）、c⁻⁴贡献、raw/residual/恢复平均速率形式；所有差异保持原始符号和历元，线性拟合仅描述差异。
7. 用准确分量时间分别进行TT→TDB→TT与TDB→TT→TDB；收敛判据由实际小量差确定。
8. 缺失小行星和KBO影响由GM/距离界估计或受控开关实验量化，报告模型不完整而非声称subps绝对准确度。

所有最终表格及图片均由脚本读取实际计算结果生成，记录数据SHA256、参数、库版本、运行耗时和命令。
