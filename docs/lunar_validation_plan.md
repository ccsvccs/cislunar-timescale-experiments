# 月球时间星历的比较对象与验证方案

本文件保存2026-11-10的初始方案；2026-11-11用户已授权实际月心实现与全覆盖比较，
后续结果见[月心全时段报告](full_span_lunar_report.md)。下文“尚未实现”描述的是方案制定时的状态。

本文件是只读文献与参考产品审计后的方案，尚未实现 TCL 积分，也没有本项目的月球数值验收结果。首阶段建议比较 **月心 TCL−TDB 对作者实际发布的 LTE440 产品**。先固定可复现的量、边界和参考版本，再另行讨论 TL 的缩放约定与月面钟固有时。

## 1. LTE440 实际验证了什么

固定来源为 [Lu、Yang、Xie arXiv:2509.18511v1](https://arxiv.org/pdf/2509.18511v1)，本地 [PDF](sources/lte440_2509.18511v1.pdf) 与 [文本](sources/lte440_v1.txt)。已视觉核查 PDF p4 的 Sec. 3 与 Fig. 1。

| 作者检验 | 原文位置 | 支持的结论与限制 |
|---|---|---|
| 半天与一天积分区间比较，差约 10 fs | p4 Sec. 3 | 同一模型的积分收敛诊断，不检验缺失物理项或输入星历的绝对准确度。 |
| 用其方法复算地心 TT−TDB，对比 DE440 内置地球时间星历；全时段差小于 1 ps | p4 Sec. 3、Fig. 1 | 检查地球版本的模型与数值计算一致性。图上方为速率差，下方为时间差。**不是将月球 TCL 与 DE440 的某个 TCL 段比较**；DE440 的现有独立时间参考是 TT−TDB。 |
| LTE430 与 LTE440 比较 | p5–7 Sec. 4.3、Figs. 2–3 | 同组作者用不同输入星历产生的月球时间星历交叉评估。差异反映动力学、输入与直接引力势版本差异，不能当作另一月球真值。 |
| 用长时段 LTE441 校正 LTE440 的长期平均系数 | p7 Sec. 4.4、式(22) | 改善长期周期与平均项的分离，不是证明完整 LTE440 物理误差为 1 ps。 |

Sec. 4.3 报告 LTE430−LTE440 在约2000年差至13 ns、约2600年差至350 ns；去趋势后的全区间差约 −7.5 至 +2.5 ns。作者认为 KBO/环的存在及月球运动改进是主要候选来源。这些数值不是 LTE440 相对真实时间的绝对误差。

Sec. 4.2（p5）仅作初步物理准确度估计：依据 DE440/441 测距残差对距离误差作数量级估计，长期速率误差约 `7e-20`，到2050年月球时间星历误差优于 `0.15 ns`；更稳健估计留待下一代 JPL 星历。式(18)的 `±1e-17` 是平均速率的拟合误差，含义也不同。结论 p7 明确把与 INPOP21a/EPM2021 月球时间星历的外部比较留作后续工作。

## 2. LTE441 漂移校正不能混入产品验收

v1 式(18)给出 `L_C,440^M = 1.4825362167e-8`；式(22)给出经 LTE441 校正的 `1.4825362217e-8`。两者差 `5e-17`。作者对分别去线性项的 LTE441 与 LTE440 残差作线性最小二乘拟合，以降低有限区间中长期周期对平均率的污染。

首阶段应比较发布产品实际包含的完整函数，保留该产品的周期项与 TPC 线性项配对。不能把式(22)系数替换进旧产品后仍称其原版 LTE440，也不能把从参考残差拟合的常数或趋势用于本项目验收。任何长期率定义研究应作为单独诊断。

## 3. 已取得产品的具体身份与读取约定

2026-11-10 本次只读检查实际存在的 `/tmp/lte440-reference-20250620.zip`。来源为作者 [20250620 Release](https://github.com/xlucn/LTE440/releases/tag/20250620) 的 [lte440-tclmtdb.zip](https://github.com/xlucn/LTE440/releases/download/20250620/lte440-tclmtdb.zip)。该2025年6月产品早于固定2025年9月论文v1；二者须分别记录身份，不能推定每个生产细节完全相同。

ZIP 内 BSP 的单段元数据：center `1000000000`，target `1000000005`，frame `1`（J2000），SPK Type 2，TDB JD 范围 **2287184.5–2688976.5**。它存储 TCL−TDB 的周期部分，X 分量单位为秒，不是距离；不能做 km→m 转换。TPC 的实际值为：

```text
BODY1000000005_RATE = +6.798355238724282D-10
```

作者 `lte440.py` 接受两部分 TDB JD；`tclmtdb(jd1,jd2)` 返回完整 TCL−TDB，`tclmtcb(jd1,jd2)` 返回 TCL−TCB。按实际示例，令 `s0=T0+TDB0`、`T0=JD 2443144.5003725`、`TDB0=-65.5e-6 s`，则：

```text
TCL−TDB = BSP_X(TDB) + RATE × (TDB−s0)  [时间间隔以秒表示]
TCL−TCB = (TCL−TDB) + TDB0 − LB/(1−LB) × (TDB−s0)
```

ZIP 附带示例输出在 `s0` 给出 TCL−TCB 约 `−3.61e-17 s`，TCL−TDB 约 `+65.5 μs`；在 J2000.0 TDB 给出 TCL−TDB `+0.49330749643254862 s`。这些是**作者随包输出**，本次未重新执行转换程序。月心锚点因此可独立检查；TPC 中正号也消除了早期手册关于平均 TCL/TDB 速率的负号笔误歧义。作者程序中一处将结果注释为 TCL−TCB，实际变量与函数返回的是 TCL−TDB，应以运算和输出列定义为准。

[作者手册 v1](https://arxiv.org/html/2506.19213v1) Sec. 2 与 [作者仓库](https://github.com/xlucn/LTE440) 可核查使用方法。BSP/TPC 可作为独立对照，禁止进入核心积分、零点校准或修正表。该 Release 未公开生产积分源码和原输入清单/哈希；不能据此确定作者使用的小天体轨道、环实现或其它全部输入身份。

## 4. 本项目首阶段的建议验收定义

被比较量固定为 `Q(TDB)=TCL(TDB,x_M(TDB))−TDB`，即月心、相同 TDB 时刻、两部分JD、SI秒。采用 IAU 2024 TCL 月心原点：在 `TCB=T0` 时 `TCL=T0`，对应 TDB 输入为 `s0`。不引入 TL、具体站点或月球自引力固有时。

1. 先完成参考读取审计：两部分JD、X单位、正负号、TPC完整线性项、锚点、插值分段边界、覆盖端点与作者示例。核查不同读取库的舍入影响，避免把时间分量当通常SPK距离。
2. 复用真实 DE440 月球质心状态；将外部势的观察中心改为月心，排除Moon自势、加入Earth，并逐项审计月球版 PN、外部非球形势与小天体直接势。物理项和输入不齐时明确标记，不以参考值补齐。
3. 先在现代区间（建议沿用 2024-01-01 至 2026-01-01，明确为 TDB 端点）报告原始时间 residual、瞬时速率 residual、独立积分差及数据/模型限制。**最大绝对原始 residual <1 ps 可作为数值一致性研究目标，尚未达到或证明可达到。** 每日采样外加关键分段边界检查不能称连续全域保证。
4. 再扩展到实际共同覆盖 JD 2287184.5–2688976.5，单独报告1100年累计结果与采样策略。现代区间通过不等于全区间通过；全区间 <1 ps 也仍只是相对发布产品的一致性目标。
5. 不拟合零点或线性趋势以通过验收。为数值稳定而从积分中减去已声明常数率时，必须在输出中精确恢复。拟合/去趋势只能作为单列归因诊断。

LTE440 的地球复算小于1 ps、本项目相对 LTE440 的月球数值 residual、LTE440 对真实月球物理时间的约0.15 ns初估是三种不同结论。当前约2 ps的地球复现缺口和原DE440小天体输入身份不明，仍可能影响月球比较；在获得实测证据前不承诺亚皮秒通过。

后续若要研究 TL，再显式选定 `TL=(1−LL)TCL+LL×TL0` 的约定并传播同一误差；若研究月面钟固有时，则另需站点轨迹/姿态、重力场和潮汐模型及独立物理误差预算。
