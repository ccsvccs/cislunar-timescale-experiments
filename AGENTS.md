# Repository agent instructions

Read and follow [AGENT.md](AGENT.md) before working in this repository. It is
the maintained source of project guidance, delegation rules and research status.

The user authorizes the main session to create, assign and coordinate subagents
for repository work. Keep the main session focused on user communication,
scientific decisions and final review; delegate substantial independent work
and return concise evidence summaries. Follow the context budget in AGENT.md.

These project instructions remain subject to higher-priority instructions,
the user's current request and the environment's actual tool permissions.
